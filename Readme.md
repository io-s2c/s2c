
# S2C - Shared Storage Consensus

![CI](https://github.com/io-s2c/s2c/actions/workflows/ci.yml/badge.svg?branch=main)
![Release](https://img.shields.io/github/v/release/io-s2c/s2c)

A full-featured state machine replication (SMR) in S3 implementation in Java. With a highly observable (Micrometer & Structured logging), virtual threads powered and lightweight core, S2C is meant for practical use in modern Java (21+) applications requiring reliable distributed coordination.

See the [design document](docs/design-doc.md) for full protocol, architecture, and internals.

S2C IS STILL IN ALPHA STATE.
